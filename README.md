
# 🥗 Muy Saludable – RESTful API Backend

This project is a RESTful API backend developed in **Node.js** and **TypeScript** for the "Muy Saludable" application. It provides personalized meal plans based on user data such as age, weight, height, and dietary goals (gain, lose, or maintain weight).


## Features

- **Express.js** framework for building RESTful APIs
- **Mysql** integration for data persistance
- **TypeScript** for type safety and scalability
- **Docker** support for containerization and deployment to Cloud Run
- Modular architecture with clear separation of concerns
## Project Structure

```bash
restServerMuySaludable/
├── api/                 # Compiled JavaScript files
├── db/                  # Database connection setup
│   └── connection.ts
├── models/              # Sequelize models
├── routes/              # API route definitions
├── controllers/         # Request handlers (logic per route)
├── .env                 # Environment variables (not committed)
├── .gitignore
├── Dockerfile
├── package.json
├── tsconfig.json
└── app.ts               # Entry point of the application

```
